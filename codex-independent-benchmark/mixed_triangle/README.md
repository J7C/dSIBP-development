# mixed_triangle

线方向固定为 `1:v1->v2` massive h、`2:v2->v3` massive h、`3:v3->v1` massless。固定 `---` 可达 `top`、三个 single 和三个两边 forest；三边 cycle 不可达。固定 `+-+` 只有 line 3 为 full，可达 `top/e3`。

全同分支 top 离散态 32；`e1/e2/e3` 分别 8/8/16；`e1_e2/e1_e3/e2_e3` 分别 1/4/4。每 sector momentum generator 为 3，active time 等于当前代表顶点数。总 relation 660、三不变量总导数 27、zero relation 0。
