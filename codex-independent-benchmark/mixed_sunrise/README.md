# mixed_sunrise

三条线均为 `v1->v2`：line 1 massive h，line 2/3 massless。共同 theta 给固定 `++` 分支 `{top,e1,e2,e3,e1_e2_e3}`；只有 single 与 triple odd subsets。固定 `+-` 只有 top。

同分支 sector 离散态依次为 `16,1,4,4,1`，active time 为 `2,1,1,1,1`，每 sector 有 6 条 momentum generators。cross top 离散态 4。每种离散态另遍历 ISP 点 `{0,0},{1,0},{0,1}`。总 relation 690、`s11` 总导数 6、zero relation 0。
