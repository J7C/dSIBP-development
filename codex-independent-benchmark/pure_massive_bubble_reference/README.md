# pure_massive_bubble_reference

两条 massive 线均有序 `v1->v2`。固定 `--` 可达 `{top,e1,e2}`，固定 `-+` 只有 top；top 离散态 16，single sector 仍枚举 remaining line 的 4 个原始端点态并在输出 canonical。每 sector 有 2 条 momentum generators。direct-h、bare-H、H-to-h 每路 152 条 relation 与 4 条 `s11` 总导数，三路合计 456/12。

reference-only 另取 `--`、`a0=2nuM`、`b0=-2nuM`、`E1=E2=i k0`、`s11=ks^2`，保存 top 16 + R1 4 个原始 endpoint states。`k0/ks` 的单积分和乘积法则共 80 条，另有 symmetry 6、parity 4。
