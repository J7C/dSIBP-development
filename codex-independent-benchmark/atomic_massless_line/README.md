# atomic_massless_line

有序线 `1:v1->v2`，top notation 为同分支 `J[{a1,a2},{{b1,n1}},{}]`、异分支 `J[{a1,a2},{{b1}},{}]`，shrink 为 `J[{a12},{{bS1}},{}]`。`n=1` 正方向固定为 `v1->v2`。

固定 `++` sector 为 `{top,e1}`，top 有 2 个离散态、2 条 active-time、1 条 momentum；`e1` 有 1/1/1。固定 `+-` 只有 top，离散态 1、time 2、momentum 1。总 relation 11，zero relation 0；本 family 没有初始化 `sij/ke`，所以总导数记录为 0。
