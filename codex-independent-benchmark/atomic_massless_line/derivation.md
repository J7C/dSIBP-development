# atomic_massless_line 推导

从 `ORACLE_DERIVATION.md` 第 1 节直接得到 `partial_u/v M0/M1`。`n=0` 无 delta；`n=1` 在第一/第二端点分别给 `-2/+2`，contact 不携带额外 `q` 或 `tau` 幂，所以 `s=z=0`、`bS0=beta1`、`a0Merged=alpha1+alpha2`。

径向导数由 `q partial_q M_n=i sigma qDelta M_{1-n}` 给出；唯一 scalar product `ell^2=propSq[1]`，故 `d/dell.ell` 闭合。端点反转保持 `M0`、翻转 `M1`；同端点的两个 regular derivative 相消，coincident `n=1` 为零。
