# pure_massless_bubble 推导

共同-theta 差值对两个 line states 展开。只有恰好一个 `n=1` 时产生对应 single shrink；`(0,0)` 与 `(1,1)` 的总 boundary 为零。因此只到达 `e1/e2`。

动量闭合由

```text
q.q = propSq1,
k.q = (s11+propSq1-propSq2)/2
```

完成，覆盖 `d/dq.q` 与 `d/dq.k`。`s11` 导数从 `k.partial_k=2s11 partial_s11` 反解，并作用于 denominator、massless exponential block 与显式系数。
