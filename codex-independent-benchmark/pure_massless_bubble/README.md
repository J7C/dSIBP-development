# pure_massless_bubble

两条线均有序 `v1->v2`。同分支 top 为 `J[{a1,a2},{{b1,n1},{b2,n2}},{}]`，cross top 两个 pack 均为 `{b}`。共同 theta 只允许 odd subset，因此固定 `--` 可达 `{top,e1,e2}`，固定 `+-` 只有 top；single contact 后未选中的 massless line 只保留 `n=0`，按逐线 convention 仍写 `{b,0}`。

同分支 top 的 `(active time, momentum, discrete)=(2,2,4)`，`e1/e2=(1,2,1)`；cross top 为 `(2,2,1)`。总 relation 26、总导数 4、zero relation 0；总导数变量为 `s11`。
