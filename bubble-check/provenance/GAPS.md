# 资料具备情况与缺口

| 核验项目 | 当前证据 | 限制及影响 |
|---|---|---|
| 计算对象、参数、版本 | 四支入口、formula/result、旧版本记录、固定源码 blob | 可追溯实际旧运行；不能称为上传时最新版计算 |
| 主积分、排列、接触扇区 | 完整 masters、context、projection/embedding、contactMaps | 本轮检查结构对应，未独立重导全部关系 |
| 生成的 DE | 四支完整 dlog 字母和矩阵，22/16维 | 不等于独立推导；原符号与 backend 序列化需区分 |
| 边界连接及留数 | 成功结果中保存完整矩阵 | 可核对其符号/有理表达式；不是成功请求 JSON 的逐字替代 |
| 边界指数、向量、权重 | 四支完整 leadingBranches、normalization、coefficient、physicalWeight | 已保存；接触18/21的平均问题可定位 |
| 成功后端原始输入 | process 中记载文件名，但四个请求文件均缺失 | 无法逐字检查实际仿射请求矩阵、初始分支编码和权重舍入；不重建来冒充原件 |
| 普通锚点初始向量、完整递推中间量 | 没有单独保存全部 primary/reference 初值及局部系数 | 无法逐步回放所有数值递推；领头数据与终值不等于完整轨迹 |
| 后端输出及路径 | 四份原输出、节点、点分配、过程日志 | 可核对计算完成及内部指标；不独立保证物理正确 |
| 逐点外部比较 | 三个点、四支J0000和K，旧误差字段 | 未覆盖所有16/22个master；参考球中点差不等于严格总误差 |
| 独立参考截断 | 旧比较保存K尾界；旧JSON保留自身状态 | rho=2.8尾界不足以认证1e-26；不补算更强界 |
| 每次参考运行的精确代码版本 | 有末态脚本及多次结果、日志 | 无逐次历史脚本快照；旧 false 字段与后续尾界分开保留 |
| 论文作者的 independent scan | 本次没有获得可识别的作者程序、201点原数据与完整设置 | 本参考不能冒称论文官方参考 |
| 201点、17/15边界两档、性能主张 | 本次三个点资料不具备 | 不宣称复现这些论文主张 |
| 修复后的因果验证 | 没有 | 无法量化已定位系数问题对终值的贡献，不能宣称全部差异已解释 |
| 上传目的地 | 现有原记录同时使用两个仓库 | 待用户唯一指定；本地完成不等于远端上传 |

已按精确文件名搜索成功请求；`initial_inventory.json` 记录了现存候选文件的大小和哈希。早期失败请求按原失败记录绑定保留，未以摘要相同为由改称成功输入。

新增内容只有说明、文本/字段提取、表格、来源清单和静态完整性验证。本轮没有运行 Wolfram、MadStree、FlintNDE、参考积分、比较脚本或候选修复。
