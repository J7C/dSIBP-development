## 结论摘要

合作者总结中的数学判据是对的：必须比较 records 重建的 `A(t)` 与解析
`d omegaPotential/dt`，而不能用高低输运阶一致代替。但其核心结论
“v0.15 普通输运把 12 条记录错误压成 7 条”在当前源码上没有复现，附件也没有提供足以复核
该特定路线的数据。

当前审计得到一个更窄但真实的高风险缺陷：普通点输运使用的 `_letters_to_system` 正确；只有
终点恰好是 DE 奇点时调用的 `_letters_to_rational_system` 曾漏乘 affine 斜率 `beta`，会改变局部
Laurent residue、Frobenius 指数及有限/发散分类。该缺陷已在本轮修复并增加回归；它不能解释
附件所称普通物理点约 2% 偏差。

边界不是统一做 `I*k0 -> +Infinity`。程序按每个顶点的 `vertexType` 分别选取使遥远过去指数
衰减的复方向。这一 Wick/阻尼约定在代数上自洽，并已由两顶点 `G++` 论文路线独立验证；但
当前没有三顶点 25 维原始积分或独立解析 oracle 覆盖完整边界向量与最终解析支。因此“三顶点
边界错误”仍是未决命题，不能由本次序列化检查证明或排除。

## 实际数据流

```text
MSDLogDE: omegaPotential, letters, letterMatrices
  -> msEvaluationParameterizedDE: 固定参数；完全相同的 letter 矩阵求和
  -> msAffineLetterData: W(s)=alpha+beta s，输出 alpha/beta/R
  -> 普通输运 _letters_to_system: pole=-alpha/beta, residue=R
  -> PartialFractionSystem: A(s)=sum R/(s-pole)

终点为奇点时另走：
  -> _letters_to_rational_system
  -> RationalMatrixSystem
  -> plan_singular_target_match / evaluate_singular_target
```

普通路线满足

\[
 \frac{R}{s+\alpha/\beta}=\frac{\beta R}{\alpha+\beta s}
 =R\frac{d}{ds}\log(\alpha+\beta s).
\]

同极点 records 在 Python 中把 residue 矩阵相加；固定参数使 Wolfram 层的 letters 完全相同时，
`GatherBy` 后也对矩阵执行 `Total`。因此 records 数减少本身不是漏项证据。

## 发现 1：末端奇点局部系统漏乘 `beta`（高）

### 预期契约

每条 record 表示 `R dlog(alpha+beta s)`，所以有理连接必须是
`beta R/(alpha+beta s)`。改写成 pole/residue 形式后，pole 是 `-alpha/beta`，在该 pole 的
residue 必须仍为 `R`。

### 修复前实现、触发条件与当前状态

- 正确普通路线：`package-MadStree/versions/MadStree-v0.15/Backend/flintnde_transport.py:287-319`。
- 修复前的错误局部路线：同文件 `487-504` 把每项构造成
  `rational_function(residue, (alpha,beta))`，即 `R/(alpha+beta s)`，没有把分子乘 `beta`。
- 该 helper 在同文件 `631-692` 被调用；触发条件是一个 affine segment 的最后一个用户点精确
  命中系统奇点，需要规划局部匹配点并对奇点求值。
- 当前实现使用 `rational_function(beta * residue, denominator)`，恢复完整 dlog 导数因子；
  普通 `_letters_to_system` 未改。

### 直接后果与传播

当 `beta != 1` 时，局部 residue 从 `R` 变为 `R/beta`。这会进入 FlintNDE 的 singularity
inventory、局部幂对数基、Frobenius 指数、奇点值以及 `removable_singularity` / `true_pole` /
`log_divergent_singularity` 分类。普通点规划和普通 Taylor 输运不调用该 helper，不受此缺陷影响。

### 最小复现

取 `alpha=-2, beta=2, R=1`。正确连接为

\[
 d\log(-2+2s)/ds=1/(s-1),\qquad A(0)=-1.
\]

当前实际执行结果：

```text
ordinary _letters_to_system A(0) = -1
local _letters_to_rational_system A(0) = -1/2
```

### 修复与验收

修复只在 MadStree adapter 的 `_letters_to_rational_system` 中把每个分子改为 `beta*residue`，
没有改 FlintNDE 的 `RationalMatrixSystem` 定义或普通 pole/residue 路线。回归增加：

1. `beta=2` 的局部/普通系统重建比较；
2. 两个不同缩放但同 pole 的 records 合并测试，总留数为 3；
3. 完整 adapter 中 `beta=2` 的 removable 末端奇点，以及既有 true pole、隐藏匹配点回归；
4. 三个非奇异样点上局部与普通连接差值球 midpoint 严格为 0。

修复后 MadStree adapter 完整回归为 `17/17`，上述定向项和既有末端 true pole、隐藏普通匹配
点、中间奇点继续输运、多点规划及正规化批处理均通过。

## Wick 方向与边界分支

当前约定为

\[
 K_v=i\,s_v E_v>0,\qquad
 s_v=-1\ (\texttt{vertexType}=+),\quad
 s_v=+1\ (\texttt{vertexType}=-).
\]

- `+` 顶点：指数 `exp(-i E_v tau_v)`，边界取 `E_v=+i K_v`；
- `-` 顶点：指数 `exp(+i E_v tau_v)`，边界取 `E_v=-i K_v`。

因 `tau_v<0`，两者都成为 `exp(K_v tau_v)` 并在遥远过去衰减。源码 authority 是
`Kernel/Core/Topology.wl:52-61` 和 `Kernel/Numerics/Boundary.wl:67-87,337-346`。反向 Wick
方向会使指数增长，不能作为同一个 Bunch-Davies 边界。

但无穷远阻尼锚点只固定起始 sheet。锚点到实物理点的路径仍必须与原始 SK `i0` 同伦；不同侧
绕过 letter hypersurface 会落在不同的 log/power branch。MadStree 按用户给定的复仿射折线输运，
不会在缺少物理 convention 映射时自动猜测合作者的变量定义。

特别地，当前两顶点 `G++` 独立验证将论文的 `exp(+i k tau)` 变量映射为 MadStree `+` 顶点的
`externalLegEnergy=-k`，并从包坐标正虚轴锚点延拓。若合作者把同一个论文 `k` 直接输入为
`externalLegEnergy=+k`，即使 DE、边界公式和数值输运各自自洽，也会比较不同的指数 convention
或不同解析支。
