# 代表推导

对 `++` top、`n=1`、第一端点：

```text
0 =
-alpha1 J[{-1,0},{{0,1}},{}]
-i E1 J[{0,0},{{0,1}},{}]
+i J[{0,0},{{-1,0}},{}]
-2 J[{-1},{{0}},{}].
```

四项依次来自顶点幂次、`+` 顶点外相位、`d_v1 M1=i q M0-2 delta` 的 regular 部分和 theta-delta。massless shrink 不产生 `b->b+1`，所以最后一项仍为 `bS=0`。

对 `++` top 的 `d/dell.ell`：

```text
0 =
(dim-beta) J[{0,0},{{0,n}},{}]
-i J[{1,0},{{-1,1-n}},{}]
+i J[{0,1},{{-1,1-n}},{}].
```

第一项是 divergence 与 `ell^-beta` 分母导数之和；后两项来自 `d_ell M_n=i(tau2-tau1)M_(1-n)`。
