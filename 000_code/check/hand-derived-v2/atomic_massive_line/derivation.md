# 代表推导

若第一端点初态为 `n1=1`，time building-block 导数先给

```text
-J[...,b-1,n1=2,...].
```

h 模式 EOM 为

```text
J[...,b-1,n1=2,...]
 = -J[...,b-1,n1=0,...]
   -(2 nuM+1)J[...,a1-1,b,n1=1,...],
```

所以 time seed 中该端点最终贡献为两项正号。H 模式只把 `2 nuM+1` 换成 `2 nuM`。

对 `++` 且 `{n1,n2}={1,0}`，第一端点 Wronskian 系数是

```text
C (-1)^(1+1) = +C,
```

而 `--` 对应

```text
C (-1)^(1+0) = -C.
```

这正是本函数族用来区分 007 默认 offset 与参考 `Vpm` 的检查。
