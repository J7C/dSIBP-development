# FlintNDE 0.5.0 开发计划

## 目标

在 0.4.0 的单变量矩阵方程输运基础上，完善用户点命中有限奇点时的局部解路由。FlintNDE
只处理矩阵方程、局部解、路径节点和多点求值，不读取 MadStree 或 dSIBP 的拓扑信息。

## 实施顺序

1. 先复制 0.4.0 为 0.5.0，保留现有普通点、避奇点和显式奇点折跃行为。
2. 在独立包实现双侧奇点局部 bucket：按目标奇点的局部收敛半径收集前后用户点，内部
   match point 只用于确定局部系数，不冒充用户节点；每个点记录 `ordinary_node` 或
   `singular_local_solution` 所有权。
3. 增加奇点目标分析：局部展开无负幂且零阶无非零 log 时返回有限值（最低正幂时为 0）；
   出现负幂或零阶 log 时返回结构化发散状态。显式命中真实 dlog pole 输出 Infinity 文本，
   可去奇点按普通数值输出，并保留分类证据。
4. 让 automatic 模式忠实处理用户点；`avoid` 仍作为显式选项，不能把绕行值误标成命中点值。
5. 增加 round-trip、双侧 bucket、有限极限、真实 pole、log 发散、点归属和错误输入测试，
   完整运行 unittest。
6. 更新 README、版本说明和技术文档，记录输出 schema、状态枚举、路径及计时字段。

## 验收

- 0.4.0 全部基线通过后才开始 0.5.0；
- 独立 `unittest discover -s tests -v` 全部通过，新增专项有明确计数；
- 普通点和现有避奇点回归通过；
- 奇点命中不会被静默绕行，结果与分类表能互相定位；
- 无 cache、pyc、临时 JSON 进入源码或 staged 集合。
