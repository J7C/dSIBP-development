# MadStree 理论推导核心逻辑

> 用途：写作时对照，防止把已被机制覆盖的对象再逐类讨论。每条只保留推导的骨架；
> 机制一旦声明，它覆盖的对象不再单独展开；约定差异只在引入处说一次。

## 2.1 记号与积分族

- 全文一个积分符号 I；指标 = sector + 时间幂移位 + mode-function state bits。
- h 块：$h^{(s)}(\nu,0)=z^{\nu}H^{(s)}_\nu$，$h^{(s)}(\nu,1)=\partial_z h^{(s)}(\nu,0)$。
  上标是 Hankel 分支，二值下标是 mode-function state。
- 一个传播子有两个 mode 函数，每顶点一个；massive 二者独立，massless full 缩成
  一个共享二态，theta-free massless 无态。
- 与文献的 ±ν 约定差异（$\nu_{\rm ref}=-\nu$，全局同步）只在 2.1 说明一次。

## 2.2 三个生成块的 IBP 关系

- 被积函数是独立因子的乘积：每顶点一个指数、每传播子端一个一阶 mode 函数系统。
  对 $\tau_v$ 求导按莱布尼兹法则一次只动一个因子，其余全是旁观者；每个因子的导数
  是它自己二态空间上的线性算子。
- 张量积只是记账：$\Emb_i(A)=\Id\otimes\cdots\otimes A\otimes\cdots\otimes\Id$ 表示
  “只动槽 $i$”。全图 $M_1$、$M_0$ = 各块生成子的嵌入之和。矩阵直积就是莱布尼兹
  法则的张量版；$M_1$ 来自 $h$ 系统的 $1/\tau$ 项与外显时间幂的配合，
  $M_0$ 来自 $-ik\sigma_2$ 与顶点指数。
- massless 额外关系的收益：主积分空间更小。

## 2.3 d log 形式微分方程

- DE 的推导一句话：对 master 向量求导，用一步递推把被求导积分约化回 master，读出
  connection。
- master 取零移位积分；$M_1$ 常数、$M_0$ 可同时对角化 → dlog 形式，字母是动量的
  线性形式，DE 的极点 = 字母的零点。

## 2.4 剩余项与接触块

- DE 的非齐次项 = 分部积分的边界项 = theta 求导的接触项；升、降两个方向在同一公式
  取不同移位。
- 对能量求导 = 把指数的 $\tau$ 换成时间幂：$\partial_{p_0}$ 抬幂一格，接触块由子
  sector 注入。
- 归一化 $J_s=\cN_s I_s$ 吸收动量依赖的 pinch 因子，使接触块无残余 pinch 前置。
- 块三角：每个 sector 只由自己和更低的 sector 提供；从最低 sector 递归求解。

## 2.5 边界条件：两层逻辑

1. 阻尼能量 $K\to\infty$ 把每个时间积分压到 $\tau\to0$：除 theta 外一切因子化为
   $(-\tau)$ 的幂，单时间积分积成 Gamma 函数。
2. 严格能量 rank 把每个 theta 冻成 0 或 1：没有 theta 耦合两个时间，主积分因子化
   为单时间积分的乘积。

- 简并多变量奇点用嵌套坐标 blow-up 化为一串单能量极限。
- 无 theta 的对象自动落入第 1 层，不单独讨论。
- 分支选择不构成第三层：不同分量间的分支由冻结的 theta 通过传播子定义选定；
  同一分量内的等时因子取两分支排列的平均（见 2.6）。
- 无外腿顶点加辅助能量，边界在 $K^{\rm aux}\to\infty$ 构造，单次扩维输运到 0。

## 2.6 共同 theta 与等时

- 多条传播子共享一个 theta：望远镜差分收集为 $\mathsf d_e$ 与 $\mathsf m_e$；
  奇子集 = 一次同时接触，权重 $2^{1-|S|}$，未选传播子留 $\mathsf m_e$。
- 顶点重合的传播子因子（含边界系数）= 两分支排列的平均，逐传播子一个平均；
  state bits 不平均。
