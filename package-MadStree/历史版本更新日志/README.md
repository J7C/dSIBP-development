# MadStree 历史版本更新日志

本目录是 MadStree 版本更新说明的长期权威归档。升级后可以删除旧源码目录、旧任务书和旧结果，但不得删除这里已经归档的更新说明。中文日志命名为 `MadStree-vX.Y.md`，已有英文日志命名为 `MadStree-vX.Y-en.md`。

Git 历史中可恢复的中文日志为 v0.4、v0.5、v0.6、v0.7、v0.8、v0.9、v0.10、v0.11、v0.13、v0.15、v0.16；对应英文日志从 v0.7 开始，但 v0.12、v0.14 等版本没有找到更新日志，因此不补造。v0.17 中英文日志取自本次整理时的工作树内容。

Git 历史中 MadStree 版本目录内的 `Vendor/FlintNDE/UPDATE_NOTES.md` 属于内嵌依赖，不是
MadStree 自身的版本日志，因此不收入本目录；当前 Vendor 也不再复制独立 FlintNDE 的集中
更新日志。每次新建版本时，先在本目录创建中英文更新日志，再从 README 与版本索引链接到这里。
