# MadStree 文档入口

MadStree 的技术文档随当前版本交付。当前 v0.15 文档位于：

- 公式手册：`../versions/MadStree-v0.15/Documentation/tree_formula.pdf`
- TeX 源文件：`../versions/MadStree-v0.15/Documentation/tree_formula.tex`
- 开发规划：`../versions/MadStree-v0.15/Documentation/DEVELOPMENT_PLAN.md`
- 当前实现清单：`../versions/MadStree-v0.15/Documentation/todolist_v0.15.md`

新版本应在自己的 `Documentation/` 中保留同类手册、规划和实现状态；验收后删除旧版本目录，
不把版本专属技术内容堆到本索引目录。
