- 公式手册：`../versions/MadStree-v0.3/Documentation/tree_formula.pdf`
- TeX 源文件：`../versions/MadStree-v0.3/Documentation/tree_formula.tex`
- 开发规划：`../versions/MadStree-v0.3/Documentation/DEVELOPMENT_PLAN.md`
- 当前实现清单：`../versions/MadStree-v0.3/Documentation/todolist_temp.md`

堆到本索引目录。
