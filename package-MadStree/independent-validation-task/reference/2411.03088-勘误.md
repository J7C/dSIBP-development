# arXiv:2411.03088 勘误

## Eq. (4.11) 的整体相位

Eq. (4.2) 定义

```text
IR = -(4 i/pi) exp(pi Im(nu1)) ks^(-2 nu1-1)
     integral_{-infinity}^0 d tau (-tau)^(2 nu0-2 nu1)
     exp(i (k12+k34) tau).
```

在与原文一致的 `i epsilon`/Laplace 分支上，令
`alpha=2 nu0-2 nu1`，直接积分给出

```text
integral = exp[-i pi (alpha+1)/2] Gamma(alpha+1)
           (k12+k34)^(-alpha-1).
```

其中

```text
exp[-i pi (alpha+1)/2]
  = -i exp[i pi (nu1-nu0)].
```

因此 Eq. (4.2) 的 prefactor 与该 `-i` 相乘后，Eq. (4.11) 对应的整体系数应以
`-4` 开头；原文印刷式以 `-4 i` 开头，相对定义积分多一个整体因子 `I`。等价地，修正式为

```text
Eq. (4.11) corrected RHS = Eq. (4.11) printed RHS / I.
```

本勘误只修正这一整体相位，不改变 master 顺序、dlog DE、Wronskian、Hankel normalization
或 Eq. (4.2) 本身。独立验证以 Eq. (4.2) 的定义积分为 authority，并把原印刷式保留为必须失败
的反事实。

## 不属于勘误的 endpoint basis 因子

Eq. (4.2) 中的 `Exp[Pi Im[nu1]]` 属于原文采用的共轭阶 endpoint basis，本身不是印刷错误。
MadStree 在两个端点使用共同 Hankel 阶；对 `nu1=I mu`，换基恒等式

```text
Exp[-Pi mu] HankelH2[-I mu,z] = HankelH2[I mu,z]
```

已经吸收这个 Boltzmann 因子。因此 MadStree 的共同阶 child normalization 不再含
`Exp[Pi Im[nu1]]`；若换基后再次乘入才是重复 normalization。论文值与 MadStree 值比较前必须
先显式化到同一 endpoint basis，不能把这一 convention 差异追加为第二条论文勘误。
