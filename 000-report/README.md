# 独立检验报告归档

本目录是项目内唯一的独立检验报告备份位置。

- 内部检验：由本 agent 在当前项目中新开独立会话，报告直接归档到这里。
- 外部检验：由外部 agent 在项目外目录完成；维护者查阅来源隔离、版本和证据后，将原报告复制到这里备份。
- 报告名：`{时间}-{版本}-{内部/外部}.md`，时间格式为 `YYYY-MM-DD-HHmm`，版本为三位程序版本号。
- 示例：`2026-07-21-1600-012-内部.md`、`2026-07-21-1600-012-外部.md`。
- 附件：放入与报告同名并追加 `-附件` 的目录。

正式归档报告及其附件保留。`report-of-report`、针对报告的 battle 和临时争论稿不作为正式报告归档；expected、check 脚本与运行结果不放入本目录。
