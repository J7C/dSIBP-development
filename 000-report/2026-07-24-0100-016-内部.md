## 4. 手推核心结果摘要

### 4.1 h 闭合微分系统（§2.2, §5）

```
∂_x F[h,s,0;ν,x] = -F[h,s,1;ν,x]
∂_x F[h,s,1;ν,x] = -F[h,s,0;ν,x] - (2ν+1)/x · F[h,s,1;ν,x]
```

矩阵形式 A_h = {{0,-1},{-1,-(2ν+1)/x}}

**推导链路**: h_ν(x) = x^{-ν} H_ν(x) → 对 Bessel 方程做变量替换 →
一阶系统封闭于 {F[h,s,0], F[h,s,1]}。

**笔记位置**: `000_note/01_h_H_differential_system.md` §2

### 4.2 裸 H 闭合系统

```
∂_x F[H,s,0] = F[H,s,1]
∂_x F[H,s,1] = (ν²/x²-1) F[H,s,0] - (1/x) F[H,s,1]
```

矩阵形式 A_H = {{0,1},{ν²/x²-1,-1/x}}

### 4.3 变换矩阵 T_Htoh

```
T = {{x^{-ν}, 0}, {-ν x^{-ν-1}, x^{-ν}}}
Det[T] = x^{-2ν}
验证: A_h = T·A_H·T^{-1} + (dT/dx)·T^{-1}  ✓
WT = Det[T] × W_H = -4i/(π x^{2ν+1}) = W_h  ✓
```

**笔记位置**: `000_note/01_h_H_differential_system.md` §4

### 4.4 Wronskian Shrink（h 基底）

| (n1,n2) | [WGreater-WLess]_{coinc} | 非零？ |
|----------|--------------------------|--------|
| (0,0) | 0 | ✗ |
| (0,1) | -4i/π · x^{-2ν-1} | ✓ |
| (1,0) | +4i/π · x^{-2ν-1} | ✓ |
| (1,1) | 0 | ✗ |

统一公式：κ = -ε_SK × (-1)^{n1} × 4i/π（n1+n2=1 时）

Shrink 编码：s=1, z=2ν → bS=b+1, bS0=b0+2ν, aMerged=a_u+a_v-1, a0Merged=a0_u+a0_v-2ν

**推导链路**: W[H^{(1)}_ν, H^{(2)}_ν] = 4i/(πx) (DLMF §10.6.1) →
代入 h=x^{-ν}H → W_h = x^{-2ν} W_H = 4i/(πx^{2ν+1}) →
在 coincidence 点 x_u=x_v 处取 [WGreater-WLess] →
只有 n1+n2=1 的反对称组合非零。

**笔记位置**: `000_note/02_wronskian_shrink.md` §2-3

### 4.5 Massless M 导数

```
∂_{τ_u} M[σ,0] = +iσq M[σ,1]  (无 δ)
∂_{τ_u} M[σ,1] = +iσq M[σ,0] - 2δ(Δ)  (有 contact)
∂_{τ_v} M[σ,0] = -iσq M[σ,1]
∂_{τ_v} M[σ,1] = -iσq M[σ,0] + 2δ(Δ)
```

Massless shrink：s=0, z=0, κ=±2（第一端点 -2，第二端点 +2）

**推导链路**: M[σ,n] = exp(iσq|Δ|) 的 n=0 和 ∂_q 的 n=1 →
∂_τ 作用在 |Δ| 上产生 sign(Δ) → 组合为 M[σ,1-n] →
n=1 时 ∂_τ sign(Δ) = 2δ(Δ) 产生 contact。

**笔记位置**: `000_note/03_massless_M_relations.md` §2
