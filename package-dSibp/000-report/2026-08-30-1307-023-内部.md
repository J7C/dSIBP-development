## 4. Mixed Bubble+Tree 全流程

### 4.1 Parity 与主积分识别

本 family 的圈传播子只有 line 1 和 line 2，分别施加

```wl
{
  b[1] + n[1, 1] + n[1, 2] -> 0,
  b[2] + n[2, 1] + n[2, 2] -> 0
}
```

line 3 是 fixed tree bridge，没有圈积分 `b[3]`，不进入 parity。正式检查扫描 310688 个普通导出
积分和全部 81 个 active masters，未发现 bridge 被写成圈幂或第三 parity 槽。

自然排序 probe 没有出现足以单独冻结 basis 的明确编号跃变。完整非负前缀 `1..24594` 返回 608 个
Kira masters，其中只有 100 项具有严格位于当前 root envelope 内部的前像，508 项依赖上边界；因此
没有把 608 项当作物理 basis。随后保持完整关系、不做 Mathematica incidence 裁剪，只扩大 root
上界并让 Kira 约化同一批候选：master 数依次为 `130 -> 106 -> 83 -> 81`。最后一次只提高实际命中的
`a[v1],a[v2]` 方向，83 项中恰有两个高时间幂候选被约掉，其余 81 项逐积分稳定，RHS 闭合且
`unreduced=0`。这 81 项才冻结为 formal active basis。

Formal Kira 中看到的 master IDs `1..81` 是冻结 active basis 后的正式映射结果，不反过来充当 basis
发现证据。

## 6. 结论与未覆盖边界

dSIBP 023.0 在任务书限定范围内通过：source-isolated general seeds/operators、公开反馈、论文两顶点
DE、pure massive bubble 与 mixed bubble+tree 的 fresh Kira 全流程均闭合。尤其是 mixed 的两条圈线
各自全偶，fixed tree bridge 始终不参与 parity。

下列内容没有被本报告扩大解释为已验证：

- single-massive sunrise 只到 general seeds/operators；没有运行 Kira、DE 或 scaling。
- massless full-line tree 的公式型 quotient reduction 仍为 `PendingRederivation`。
- pure bubble 的既有 reference producer 和 reference Kira 没有重跑。
- mixed reduction 只覆盖任务书声明的 `+++` 与两条 cycle-even parity。
- mixed reduction scaling 只在记录的 exact point 认证；全符号齐次性由独立 source-level `81/81`
  identity 提供，而不是由定点矩阵外推。
