# 独立检验报告归档

本目录是项目内唯一的独立检验报告备份位置。归档只保留仍对应工作树中保留版本、且没有被后续同类报告取代的独立证据；开发错误日志、未完成报告和已删除代码版本的报告从 Git history 追溯。

- 内部检验：由本 agent 在当前项目中新开独立会话，报告直接归档到这里。
- 外部检验：由外部 agent 在项目外目录完成；维护者查阅来源隔离、版本和证据后，将原报告复制到这里备份。
- 报告名：`{时间}-{版本}-{内部/外部}.md`，时间格式为 `YYYY-MM-DD-HHmm`，版本为三位程序版本号。
- 示例：`2026-07-21-1600-012-内部.md`、`2026-07-21-1600-012-外部.md`。
- 附件：放入与报告同名并追加 `-附件` 的目录。

当前保留 `2026-07-24-1124-016-外部.md`，作为冻结 016 的最新外部增量报告。018.1 尚未完成当前任务书要求的 source-isolated 独立 benchmark，因此本目录没有伪造 018.1 的正式通过报告。

`report-of-report`、针对报告的 battle、开发维护日志、未完成执行稿和临时争论稿不作为正式报告归档；expected、check 脚本与运行结果不放入本目录。历史报告删除不改变技术文档中的当前公式或进度表中的历史事实。
