## 2. 已发现不符合与责任判定

### N5. Reference/package 能量 adapter 符号写反

reference `Vpm=0` 的 time-IBP 相位项为 `-I P_ref`，package `--` 分支为 `+I P_pkg`，故正确映射是

```text
P_pkg = -P_ref = +I k0,
P1 = P2 = P_ref = -P0 = -I k0.
```

旧任务书和 closed-loop example 写成 `P1=P2=P0=-I k0`，并使用 `{P1->P0,P2->P0}`。责任判定：不是独立手推错误，也不是 package 的 IBP/DE 算法缺陷；是 benchmark/example 的 adapter convention 错误。现已改为 `{P1->-P0,P2->-P0}`，并同步 active 17、辅助 20/21 的显式能量符号。修正后第 17 项不再需要额外翻号，Kira 到物理 basis 的四个 R1 normalization 均为 `+ks`。

### N6. `002 bubble_de.m` 的物理变量恢复缺少 degree conjugation

`002` 对所有矩阵元统一除以 `ks`，但 19 个 reference Kira masters 的 scaling degree 不相同。其 degree 分块为前 5 个 `-18/11`、随后 9 个 `-29/11`、随后 4 个 `-18/11`、最后 1 个 `-7/11`。因此字面恢复在 `P0`、`ks` 两个矩阵中各留下 `74/361` 个非零差值。

正确恢复令 `L=DiagonalMatrix[ks^degrees]`，并使用 `L . A(P0/ks) . Inverse[L] / ks`。责任判定：这是 reference `002` 的变量恢复限制，不是 package 缺陷。该 `74+74` 只作为诊断保留，不计入通过条件。
