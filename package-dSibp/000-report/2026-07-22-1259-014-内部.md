## 1. 检验范围与来源边界

本轮只检验新增 tree 微分方程双路线，不重跑 Kira、Fermat 或 reduction。独立路线先读取 `codex-independent-benchmark/tree/` 中已冻结的 Eq. (3.53)--(3.55)、common-theta 与 dlog expected，再加载单文件 package；冻结 expected 未按 package actual 改写。

比较双方固定使用 `DSTreeDLogDE[context]["masters"]` 给出的同序 `{sectorKey,integral,coefficient}` masters。normalization `N_s` 是 master 定义的一部分，因此 naive 路线必须同时包含积分导数与 `D[N_s,variable] J_s`。

## 2. 两条实现路线

1. Naive 路线：`DSTreeNaiveIBP` 对每个 sector、master 和顶点生成 `a_v=1` 的 loop representative，调用投影后的 `dtau`，联立有限 tagged linear system，并在固定 masters 下求出 reduction；`DSTreeNaiveDE` 再对顶点能量和 massive-leg `treeEnergy` 求导并约回同一 normalized basis。
2. 公式路线：`repIterative0`/`repIterative` 直接生成 general 幂次的单步与终点迭代约化，`DSTreeDLogDE` 按 Eq. (3.53)--(3.55) 组装 dlog connection。

Naive 路线的结果记录 `formulaDLogUsedQ -> False`；它不调用 `repIterative`、`Aplus/Aminus` 或公式型 dlog 矩阵。两条路线只共享 topology convention、sector metadata 和指定 master list。
