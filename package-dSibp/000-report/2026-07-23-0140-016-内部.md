## 6. 关键交叉验证

### 图论、routing 与表示

- bubble+bridge、self-loop、三平行边加 bridge 的结构圈数、bridge/cycle 分类和 triple-contact root inheritance 均通过。
- exact/over/under 显式双动量列表及复合方向、符号、非法 support 负例均通过。
- cycle line 只保留 cycle pack；bridge/fixed line 不产生 `b/bS` shift，固定幂移由显式模长系数承担。
- `timeOnly` 使用 direct `J[vertexPacks]`，不生成 momentum generator 或 ISP gate。

### pure-time/tree

两顶点和三顶点的 direct seed、naive DE、dlog、solve residual、symbolic `repIterative` 与确定性有理数交叉验证全部通过。最终修复后的关键结果为：

### 参数与 API

- mixed `ds[c[u] J1+d[u] J2,u]` 的显式系数导数、cycle 原子导数、fixed-line 径向导数和顶点相位链式法则通过。
- `Sqrt[(u+z)^2]` 只在独立模长物理正支 `u+z>0` 下用 `Refine` 比较；未使用 `PowerExpand`。
- 欠完备与过完备参数规则均按 contract 拒绝 derivative/inverse 能力。
- `DSPublicAPI[]` 共 `29` 个公开函数，与 `coverage_manifest.wl` 集合严格一致；每个 example 的声明调用和最终手册函数名覆盖均通过。

## 7. 缺陷闭环

独立比较曾发现并由维护侧修复以下真实 package 问题：

1. 过完备 loop 声明误触发欠完备 ISP fatal gate。
2. fixed h `n=1` 径向导数残留未解析 `shiftVertexA`。
3. mixed parameter redefinition 未关闭歧义 inverse/derivative。
4. `repIterative` 使用 notation `sE`，而非 line 声明的 `treeEnergy`；导致两、三顶点 symbolic 与 rational 四项失败。
5. 修复 public context overload 后，`rep2innerform` 只检查局部 coordinate audit，绕过 topology 的 `inverseKinematicsUsableQ=False`；最终增加 topology capability gate 后修复。

最终冻结 package 对上述项目全部通过，不再有已知 package defect。
