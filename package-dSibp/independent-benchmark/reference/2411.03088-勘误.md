# arXiv:2411.03088 勘误

## Eq. (4.11) 的整体相位

由 Eq. (4.2) 的定义积分，在同一 `i epsilon`/Laplace 分支上取
`alpha=2 nu0-2 nu1`，有

```text
integral_{-infinity}^0 d tau (-tau)^alpha exp(i K tau)
  = exp[-i pi (alpha+1)/2] Gamma(alpha+1) K^(-alpha-1),

exp[-i pi (alpha+1)/2]
  = -i exp[i pi (nu1-nu0)].
```

这个 `-i` 与 Eq. (4.2) 的 `-(4 i/pi)` 相乘后给出以 `-4/pi` 开头的系数。原文
Eq. (4.11) 以 `-4 i/pi` 开头，因此相对 Eq. (4.2) 定义积分多一个整体因子 `I`：

```text
Eq. (4.11) corrected RHS = Eq. (4.11) printed RHS / I.
```

本勘误不改变 dSIBP 第 15.6 节使用的 master、DE 或 Eq. (4.2) normalization provenance；
dSIBP 不生成该 family 的边界，本式只用于独立来源审计和防止错误 oracle 被再次采用。

## 不属于勘误的 endpoint basis 因子

Eq. (4.2) 中的 `Exp[Pi Im[nu1]]` 属于原文采用的共轭阶 endpoint basis，本身不是印刷错误。
对 `nu1=I mu`，它与

```text
Exp[-Pi mu] HankelH2[-I mu,z] = HankelH2[I mu,z]
```

描述的共同阶换基相关。dSIBP 的独立 expected 按任务书冻结的 endpoint convention 读取 Eq. (4.2)，
不得因为 MadStree 在共同 Hankel 阶 basis 中吸收该因子，就从 dSIBP 的论文 expected 中删除它。
只有在已经执行共同阶换基后又乘一次该因子，才构成重复 normalization；这不是第二条论文勘误。
